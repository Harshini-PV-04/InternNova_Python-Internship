# Student Management System

## Project Description

The Student Management System is a Python-based application developed as the
final project for the InternNova Python Internship.

The project is designed to manage student information and demonstrate the
Python concepts learned throughout the internship.

## Features

- Add student details
- Display student details
- Search for students
- Manage student records
- Store student data using a file
- Handle invalid user input
- Use functions and classes
- Object-Oriented Programming implementation
- Date and time functionality
- Simple menu-driven interface

## Technologies Used

- Python 3
- Visual Studio Code
- Git
- GitHub

The project demonstrates:

## Installation / Setup

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Make sure Python is installed correctly.
5. Run the `main.py` file.
